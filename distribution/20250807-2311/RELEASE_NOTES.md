# uHabits - Global Daily Performance Dashboard

## Version: 20250807-2311
## Enhancement: Global Daily Performance Dashboard

### What's New:
This version adds a **Global Daily Performance Dashboard** to the main habits screen, giving you instant access to your overall daily scores across all habits.

### New Features:

#### 🏆 Main Screen Dashboard
- **Today's Score**: Shows your current daily performance score (0-100)
- **Performance Category**: Displays your performance level (Excellent, Good, Average, Poor)
- **Habit Completion**: Shows completed vs total habits for today
- **Yesterday Comparison**: Visual trend indicator comparing today vs yesterday
- **Weekly Average**: Your average performance for the past 7 days
- **Mini Chart**: 7-day trend visualization with color-coded performance bars

#### 📊 How It Works:
- **Scoring Algorithm**: 
  - Base score calculated from habit completion rates
  - Bonus points for consistency (completing habits 5+ days/week)
  - Streak bonuses for active habit streaks
  - Weekend completion bonuses
  - Partial credit for numerical habits based on target achievement

- **Performance Categories**:
  - **Excellent**: 80-100 points (Green)
  - **Good**: 60-79 points (Blue)
  - **Average**: 40-59 points (Orange)
  - **Poor**: 0-39 points (Red)

#### 🚀 Where to Find It:
1. Open the uHabits app
2. On the main screen, you'll see the "Daily Performance" card at the top
3. It displays immediately below the header and above your habits list
4. The dashboard updates automatically when you complete habits

#### 💡 Dashboard Components:
- **Large Score Display**: Your current daily score prominently shown
- **Trend Arrows**: ↗ (improving), ↘ (declining), → (stable)
- **Color-Coded Categories**: Instant visual feedback on your performance
- **Mini Trend Chart**: See your week at a glance with colored bars
- **Real-Time Updates**: Changes as you complete or modify habits

#### 🎯 Benefits:
- **Instant Overview**: See your general performance without drilling into individual habits
- **Motivation**: Visual feedback encourages consistent habit completion
- **Trend Awareness**: Quickly spot improving or declining patterns
- **Goal Setting**: Use the 100-point scale to set daily performance targets

### Installation:
1. Install the APK file: `uHabits-GlobalDashboard-20250807-2311-debug.apk`
2. The dashboard will appear immediately on the main screen
3. Start completing habits to see your daily score build up!

### Technical Details:
- Calculates scores across all active (non-archived) habits
- Updates in real-time as you complete habits
- Stores 30 days of historical data for trends
- Optimized for performance with background calculations

This enhancement provides the exact functionality you requested: **visualization that displays performance per day** and a **score per day to compare performance in general based on the number of habits done per day**.
