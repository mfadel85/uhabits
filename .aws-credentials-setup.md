# AWS Credentials Setup Guide

## 🔐 Secure Credential Management

### Method 1: AWS CLI Configuration (Recommended)
```bash
# Configure AWS credentials securely
aws configure

# You'll be prompted for:
# AWS Access Key ID: [Enter your access key]
# AWS Secret Access Key: [Enter your secret key]  
# Default region name: us-east-1
# Default output format: json
```

This stores credentials in:
- Linux/macOS: `~/.aws/credentials`
- Windows: `%USERPROFILE%\.aws\credentials`

### Method 2: Environment Variables
```bash
# Add to your ~/.bashrc or ~/.zshrc
export AWS_ACCESS_KEY_ID="your_access_key_here"
export AWS_SECRET_ACCESS_KEY="your_secret_key_here"
export AWS_DEFAULT_REGION="us-east-1"

# Reload your shell
source ~/.bashrc
```

### Method 3: IAM Roles (For EC2/Lambda)
If running on AWS infrastructure, use IAM roles instead of access keys.

## 🚫 What NOT to Do

### ❌ Never store in code files:
- `deploy_cloud_analytics.sh`
- `android_config.json`
- Git repositories
- Plain text files in project directories

### ❌ Never hardcode:
```bash
# DON'T DO THIS!
AWS_ACCESS_KEY="AKIAIOSFODNN7EXAMPLE"
AWS_SECRET_KEY="wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY"
```

## ✅ Android App Security

### For the mobile app, use:
1. **API Gateway API Keys** (not AWS credentials)
2. **Environment-specific config files** (excluded from git)
3. **Android Keystore** for sensitive data

### Android Configuration:
```json
// android_config.json (git-ignored)
{
    "api_endpoint": "https://your-api.execute-api.us-east-1.amazonaws.com/prod/sync",
    "api_key": "your-api-gateway-key-here",
    "region": "us-east-1"
}
```

## 🔒 Security Layers

1. **AWS CLI**: Handles deployment credentials
2. **API Gateway**: Manages app access via API keys
3. **IAM Roles**: Control service permissions
4. **Git Ignore**: Excludes sensitive files
5. **Environment Variables**: Runtime configuration

## 📱 Mobile App Integration

The Android app only needs:
- API Gateway endpoint URL
- API Gateway API key (not AWS credentials)
- Region name

These are less sensitive and can be stored in local config files.
